## 📌 Sobre o Projeto

Este projeto tem como objetivo organizar e analisar dados relacionados à falta de água no bairro Vila Palmeira, localizado em São Luís, Maranhão.

A proposta faz parte de um desafio de Ciência de Dados, que busca demonstrar como uma planilha bem estruturada pode transformar dados do cotidiano em informações úteis para a compreensão de problemas reais.

Por meio do Google Sheets, a atividade explora a organização de dados, a utilização de fórmulas e a análise de informações para identificar padrões relacionados às interrupções no abastecimento de água.

## 🎯 Objetivos

- Organizar dados em uma planilha estruturada.
- Analisar a frequência das ocorrências de falta de água.
- Identificar as ruas mais afetadas, conforme os dados utilizados.
- Utilizar fórmulas e recursos do Google Sheets para interpretar informações.
- Apresentar os resultados de forma clara e visual.

## 📈 Resultados Esperados

A análise permite demonstrar como a organização de dados pode contribuir para:

- Compreender a distribuição das ocorrências de falta de água.
- Comparar a frequência dos registros entre diferentes ruas.
- Identificar possíveis padrões nos dados analisados.
- Facilitar a interpretação das informações por meio de tabelas e gráficos.

## ⚠️ Observação sobre os Dados

Caso sejam utilizados dados fictícios, eles serão considerados simulações para fins educacionais. Os resultados não devem ser interpretados como registros oficiais das interrupções no abastecimento de água do bairro.
